## 弾き語りで重要なのはベース音

<div class="table-container">

[1 ～ 2 弦でのドレミの練習表]

さて上記表のように、2弦1フレット～1弦8フレットまでのドレミ・・・ド(1オクターブ高いドレミ)ができるようになったら、色々な場所でドレミ・・・ドを探して弾ける練習をする事になります。
ここまででは5弦3フレットのド(上表の＊)～2弦1フレットのドまでの音階を弾けるようになり、更にその上の(1オクターブ高い)ドレミ・・・ド、つまり2弦1フレット～1弦8フレットまでのドレミ・・・ドが弾けるようになったわけです。

しかしながら何かの楽曲を演奏するためには **1オクターブ低いミ(6弦開放)** までを追加練習する必要があります。
例えば、ConGや、G/F#、D/Aなど色んなコードがあったりしますが、これらはだいたいベース音を必要としています。演奏する際に、コードからコードへの繋がりを作って滑らかにコードチェンジをするという感じですが、慣れない内はベース音はすっ飛ばしても良いながらも、できるだけ弾けるようにしたいわけです。
それらを押さえるために、本来の押さえ方と若干違うフォームをする必要もあります。

### C/Gで説明すると

指は次のようになっています。番号がふってあります。

> ConGや、G/F#、D/Aなどは、オンコードあるいは分数コードと呼ばれ、[Chord]/[Bass]や[Chord]on[Bass]というような構造になっている

<div class="table-container">

[ConGあるいはC/G]
| 0f | 1f | 2f | 3f | 4f |
|:--:|:--:|:--:|:--:|:--:|
| E  |    |    |    |    |
| B  | 1  |    |    |    |
| G  |    |    |    |    |
| D  |    | 2  |    |    |
| A  |    |    | 4  |    |
| E  |    |    | 3  |    |

</div>

例えば上記のようなC/Gと言うコード。3は薬指、4は小指ですが、3と4はどっちでもいいじゃないかと思いがちです。絶対にそうかというとそう言うわけでもないですが、C→C/G→Fというようなコード進行はよくあります。この時に、4が6弦を押さえているよりも表のようであれば2-3-4をそのまま1つずつ下げればよいわけで、簡単にコードチェンジできます。
このような理由もあり、また1-2-3で、肝心の5弦3フレットのCを抜いても6弦3フレットのGを狙う事もあり、できるだけ楽にかつ素早くコードチェンジもベース音も鳴らせる方法を考える必要がある場合もあります。

STEP1～4まではやってみるとわかるように、2弦1フレットの「ド」以降の1弦を使用するやり方では指の運びに無理があるような感じがしないでしょうか？

STEP5の一例として±0オクターブの「ド((いわゆる普通のド、5弦3フレットのド))」を5弦3フレットではなく、6弦8フレットとして始めてみるやり方もあります。下記の7～10フレットを使用した縦移動のドレミを練習してみるがそのひとつのやり方です。

<u>横の(指の)動き</u>はトリッキーな奏法ができるのですが、案外移動に手間取ることが多いのです。逆に縦移動は<u>より速く目的の音を探せます</u>。コンパクトに移動できる分、速く広い音域が弾けると言う事です。

> この後説明していくコードチェンジについても、横に大きく移動するより縦に移動する方が速くコードチェンジができるため、EとAのコードを基準に各ポジション上下セットで覚えると良いのですが、まだ基礎もしくは基礎の応用なのでまた後の方で説明することにします。

さらに、ギターを弾き語りする時により上手に聴かせるためには**ベース音がとても重要**。  
平坦にコードをかき鳴らすだけではその激しい思いは伝えられても上手さをアピールすることはできません。
そこで、ピッキングストロークやアルペジオなども含めベース音を気にしながら弾くとたいした事はしていないのに上手いという印象与えることができたりもします。

そのために5、6弦の音のポジションはせめて5フレットあたりまではギターを始めたばかりであっても覚えた方がいいでしょう。更に、1弦と6弦は同じ音の配置になっているはずなので、**1弦が覚えられたら6弦もおのずと理解している**という事になります。

#### 7 ～ 10フレットを使用した縦移動のドレミを練習してみる

![開放弦を含まないドレミ](../img/7f_10f_doremi.svg){class="w-full"}

このやり方では、開放弦を含みません。いわゆる縦移動の運指練習のひとつとなります。  
こういうふうにいろんな所でドレミを弾く練習をしてみるとギターの構造もわかり、後々非常に役に立つので是非練習してみて下さい。  
また、オススメの練習ポジションは、

- 3～5フレット付近を使用した6弦3フレット「ソ」～1弦5フレット「ラ」あたりまでの練習
- 5～8フレットを利用する6弦5フレット「ラ」～ 1弦8フレット「ド」
- 6弦12フレット「ミ」～ 1弦15フレット「ソ」
  あたりのこれら縦移動での音階を弾く練習等をしておくと良いと思います。

更に、他にもいろいろな方法で目的の音を見つけ、そこからドレミの練習ができるようにすると尚良いです。

> ネックの上にたいていのギターはポジションマークというのがついている。これを頼りにすぐに目的のフレットに移動できるように練習すると尚良い。そのために、まず6弦の音の配置を必ず覚える。これは後々コードを覚える際にも必ず有効になるだろう。

### スケール練習の後で コードC を押さえてみる

ある程度スケール練習をして指が動くようになってくれば、いよいよコードを押さえてみよう。コードを押さえるだけなら別にスケールの練習は**必要ないかもしれません**。しかしコードチェンジが絡んでくるとスケールの練習ほど有効なものはありません。スケール練習はできるだけ頻繁に練習した方がいいですね。

図：音階とギターの押弦、開放弦対応表
![図：音階とギターの押弦、開放弦対応表](../img/scale.svg)

この開放弦を除く赤で塗った部分をずっと押さえたまま、一度1～6弦を全てを鳴らしてみると**和音が鳴ります**。これが「C」なのです。

先ほどから、ただ単に「C」と書いてますが、これは「C メジャー((長調：明るい音、あるいはメジャー C))」というのを略してあります(コードについて詳しくはまた後述で)。

> Cmajというコードもあるので、単純に「C」とだけ言う。

どうでしょうか？ちゃんと綺麗な「C」が鳴ったでしょうか？

もしうまく鳴っていないと思ったなら、まず左手はCのコードを押さえたまま、右手の親指の位置確認、あるいはピックを持っているならそのピックで 6弦から順に1弦に向かって一本づつ鳴らしていくと、どの弦がうまく鳴っていないのかを把握できます。

鳴っていない弦が**なぜに鳴っていないかを把握するのが大切**であって、すぐに鳴らせる人はこれからの文を読み飛ばしても大丈夫。とりあえずはできない人に向けて。

このCと言うコードをうまく押さえるためのポイントはいくつかあります。

1. 指（第一間接）を指板にできるだけ真っ直ぐに立てること。そのために爪は短く切ったほうが良い。
2. 指はできるだけフレットの近くを押さえるようにすること。2フレットを押さえるならできるだけ3フレットに近い所を押さえる
3. ドレミファソ・・・をすばやくできるように練習を繰り返すこと。
4. 姿勢を正しくする。ギターを太ももの上にできるだけ垂直になるように抱える。ギターが天井に向けて傾きをもってくると手首が前に出せなくなったりして、1.で言うところの指が指板に垂直に立てられなくなる。矯正方法としてストラップをかけ立って練習するというのも手だ。
5. 長銃を構えるように右利きなら右手が右腰に左手が左胸の前に来るぐらいでギターを構える。
6. 手のひらとネックの間に少し空間ができるぐらいに手首を前に出す。

これらを守ることで、綺麗にCのコードが弾けるようになる(はず)。そして、最終的には**左手を見ずに押さえられるようにする**こと。手が勝手にそのポジションに移動できるようになればしめたもの。

1.について、真っ直ぐに立てる意味としては、他の弦に押さえている指が干渉しないようにすると言う意味であって、真っ直ぐだけでは少し足りません。

実際には真っ直ぐではなく、指は外に倒し気味になっていて、触れるとすればコードによって人差し指の付け根あたりがネックに触れるぐらいになるのではなかろうかと思います。  
これらは6.に関係しています。そして、6は、4であったり5にも関係しています。

{ytp::https://youtu.be/0cHeNscKZN0::Tommy Emmanue - Somewhere Over The Rainbow}

我らが[Tommy Emmanuel](https://www.youtube.com/channel/UCL-0gAth4u6Wp-9_98XU3nA){title="Youtubeのチャンネルへのリンクです"}おじさんのギターの構え方をみて下さい。まず真正面に構えてないのがわかるでしょうか？右足の付け根にギターの凹んでる部分を乗せてますよね？正解はここです。

初心者は真正面で構えがちでこのおじさんの状態から左手を自分の方に引いてしまいギターを正面に向けてしまうため、左手の可動域が制限されてしまいます。右利きなら引くのは右手側、つまりボディ側です。  
左手はおおよそ左胸の前に来るぐらいの感じで、おじさんのように構えればとても自然な角度で左手がセットできます。

この自然な角度というのが重要です。初心者はギターに自分の体を合わせようとしてしまいますが、それは間違いで、自分の体が使いやすいポジションにギターを持つべきなのです。

左手が十分にフリーになればアコギのネックぐらいなら小学生でも握れるのですから、構えた後で6弦に指が届かないなんてことはないのです。もしできないのであればそれは構え方から既に間違っていると認識して下さい。
